# ForgeShell unassisted usability test

Give a tester the device without explaining the menu structure. Tell them only
that SELECT returns to the old launcher if they feel stuck. Record success,
time, hesitation, wrong turns, and their words rather than coaching them.

Ask the tester to:

1. finish first-run setup while keeping GMenu2X as default;
2. find and launch a named game;
3. add that game to Favorites;
4. return to it from Home;
5. find another game with Search;
6. open Game Options and change then reset one setting;
7. create a save backup;
8. find the hardware report;
9. enable high contrast and then restore it;
10. enter Safe Mode and explain what changed;
11. return to GMenu2X;
12. shut down safely.

Pass criteria are at least 90% task completion without coaching, no destructive
misunderstandings, clear recovery discovery, and no repeated confusion about
A/B/START/SELECT. Prioritize fixes for hesitation shared by multiple testers.
Use `docs/usability-test.csv` for results.
