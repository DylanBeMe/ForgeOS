# Security policy

ForgeOS is beta firmware. A defect can cause data loss or leave a device unable
to boot from the affected card. Always retain an original or known-good card.

Please report security-sensitive issues privately through GitHub's **Report a
vulnerability** feature. Do not include ROMs, BIOS files, personal save data, or
private credentials. Include the affected version, device, threat scenario, and
a minimal reproduction when possible.

Only the latest release line receives security fixes. Public bug reports are
appropriate for non-sensitive crashes, UI problems, and compatibility issues.
